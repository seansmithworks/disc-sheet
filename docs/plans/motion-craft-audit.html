Motion craft audit

Project: disc-sheet 2026-09-10 Findings
Verdict

The morph did not get slower today. The glow did the damage: it makes Chrome repaint a 40px blur every frame, nine times the paint work of the plain shadow, and it keeps painting while the sheet sits open. The flare is the same layer at its first frames, spread wide around a still-tiny shape.

Side-by-side against Aug 30 (before the close retune) and this morning, glow off, 60fps agent-browser clips: all three render the same number of distinct frames per open+close once the browser is warm (62–72). The first recording after a browser launch renders half as many (34) on any version. "Smoother in the past" is cold-start and machine load, not a code change.

The pop you saw on all three builds was a duplicate shadow: the resting disc painted the silhouette shadow twice, and the open's first frame dropped one. Fixed in .triggerSurface. The glow is a recording aid, not a fixture, so it is not worth rebuilding. Judge smoothness with it off; make smoothness a number the tuner shows, so this never comes down to memory again.

Findings

  • Today's library changes cost nothing measurable. Same open+close on this morning's commit vs now, glow off: paint work 399ms vs 347ms, one ~50ms stall on the sheet's first frame in both. The X spin and the gated sheet shadow run after the morph settles.
  • The glow is the jank. Glow on, same run: paint work 3070ms. It never shows in frame-callback timing (which is why I reported 120fps earlier — wrong instrument): blur is painted off the main thread and starves the compositor instead. Your clip shows it: a 150ms hole mid-open and 333ms + 267ms holes while the sheet sat open doing nothing but spinning the glow.
  • The flare is proportion, not opacity. Spread is fixed pixels (56 length + 40 blur ≈ 100px halo). At frame 3 of the open that is a ~360px halo around a 160px shape, and opacity is already climbing. The sheet then grows into its own glow.
  • Two Emil rules broken at once. Only transform and opacity should animate; the glow animates a filter blur on an element that changes size every frame, plus a gradient angle via @property. Both force a full repaint per frame.
